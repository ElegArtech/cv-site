# Signaler un problème de sécurité

Pour signaler une vulnérabilité ou une donnée publiée involontairement, écrire
à [contact@alexandre-berge.fr](mailto:contact@alexandre-berge.fr).
Ne pas publier de données sensibles, de secrets ou de détails d’exploitation
dans une issue publique.

Préciser la page ou le fichier concerné, l’impact observé et les étapes de
reproduction, en masquant les données sensibles. Aucun délai de réponse garanti
n’est annoncé pour ce site personnel.

La version maintenue est celle de la branche `main`. Ce dépôt publie un site
statique : le CV et les présentations de projets. Les logiciels présentés ont
leurs propres dépôts et leurs propres modalités de signalement.
